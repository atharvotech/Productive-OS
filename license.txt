2. SYSTEM-LEVEL MODIFICATIONS — IMPORTANT NOTICE
──────────────────────────────────────────────────
By installing this software, you acknowledge and accept that Productive-OS
makes active, system-level changes to your Windows operating system,
including but not limited to:

  • Writing to the Windows Registry (HKEY_LOCAL_MACHINE and
    HKEY_CURRENT_USER hives) to enforce focus policies and extension
    lockdown via Group Policy keys.

  • Modifying system DNS settings via the Windows "netsh" command-line
    utility to activate Cloudflare Family DNS (1.1.1.3) during focus
    sessions.

  • Installing a persistent task in Windows Task Scheduler to enable
    the self-healing watchdog (auto-restart on process kill).

  • Using Win32 API hooks (WMI Win32_ProcessStartTrace,
    SetWinEventHook) to monitor and terminate foreground processes
    classified as games or distractions during an active study session.

  • Forcefully terminating third-party processes using psutil and the
    Windows process management API when a focus session is active.

These changes are intentional and are the core mechanism through which
Productive-OS enforces focus sessions. They are reversed (where applicable)
when a session ends or when the engine is disabled via the admin password.
